# Runbook: роботы типа emulator

## Робот не присылает heartbeat
1. Проверьте, запущен ли процесс эмулятора.
2. Проверьте доступность Django API (порт 8000).
3. Если робот получил команду kill или stop, его нужно запустить заново.

## Команды завершаются с ошибкой
В эмуляторе около 10% команд падают специально, для тестов.
Если процент падений заметно выше, проверьте историю событий робота.

## Робот завис в статусе paused
Отправьте команду resume.
